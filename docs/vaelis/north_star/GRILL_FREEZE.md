## 三级 Agent 与算力（2026-08-24 修订，详见 ADR-0011）

| 层 | 角色 | 模型 / 算力 |
|---|---|---|
| **L1** | 常驻秘书，你直接对话，与 Mind 深度结合；只统筹 / 决策 / 派工 / 验收 | 市面最好（当前 **Kimi K3**） |
| **L2** | 每个项目或专职任务一个，有记忆，领域闭环 | 便宜模型或 aigw 聚合额度 |
| **L3** | 专能子 Agent + **GUI 闭源软件执行体**（额度无法转 API 的） | 尽量零 token，走 Pico HID |

| ID | 冻结 |
|---|---|
| 模型路由 | 配置层提供**角色 → 模型**路由；L1 与 L2 必须不同且可配置 |
| L1 成本纪律 | L1 **不参与**逐条分类、抽取与工具循环，只收摘要。K3 输出 ¥100/M 且始终思考（推理计入输出），这是预算硬约束 |
| 会话隔离 | L1 与 L2 用**独立会话**，不在同一条消息历史中切换模型 |
| L1 禁区 | **永不**用 GUI/HID 免费额度充当 L1 |
| 术语 | 旧文中「Master」= L1；「Marvis」原为类比，指 **L2 级项目 Agent**，不特指某软件 |

## HID / GUI 执行体（L3）

| ID | 冻结 |
|---|---|
| **H3** | 最终目标：多号串行轮转、保活抢额度、积极恢复（个人学习向）。现硬件 1 PC + 1 Pico 2W → **串行**；多号/保活等**接口与需求预留**。 |
| **C1** | 验证码：挂起并推你手过，过完继续；第三方打码等只预留接口。 |
| **H2 排队** | Pico 仅一只，多 Agent 争抢前台须用**优先级队列**：前台交互 > 时效任务 > 夜间批量；同级 FIFO；带单任务时间片上限（超时释放重排），手动交互可抢占。现有 `ScreenLock` 只是忙等互斥锁，需升级。 |

## 记忆脑（Mind）

| ID | 冻结 |
|---|---|
| 记忆脑 | **Mind** = Vaelis 官方长期记忆 / 知识脑 |
| 默认配置方向 | `memory.provider: mind`（适配器实现按切片推进） |
| L1↔Mind | 检索与摘要注入；**禁止**整库灌进 L1 上下文 |
| **读**（2026-08-24） | **L2 直接读**自己项目子树；不经 L1 转述（避免让 ¥100/M 的模型搬砖） |
| **写**（2026-08-24） | 统一经一个**不带 LLM 的 Mind 写入服务**：串行队列 + 安全前缀校验 + 批量提交 + 提交前 verifier 预检 |
| 状态 vs 知识 | Mind 是**知识与画像**真源，**不是**运行时状态真源；日程/DDL 等运行时状态存 SQLite（ADR-0007） |
| **R3（路径）** | 逻辑真源 = **唯一 git remote**；本机路径只认 `MIND_ROOT`（或等价配置），代码不写死盘符 |

## 修订记录

### 2026-08-24

1. **三级 Agent 架构入契约**：L1（最好模型，只统筹）/ L2（便宜模型，领域闭环）/ L3（GUI 执行体，尽量零 token）。原「Master + Marvis」术语升级，Marvis 明确为类比而非特定软件。见 ADR-0011。
2. **L1 模型改为市面最好（当前 Kimi K3）**，替代原「冷启动 DeepSeek」；并新增 L1 成本纪律与会话隔离条款（K3 始终思考、推理计入输出、不应在推理链中途换模型）。
3. **Pico 排队升级为优先级队列（H2）**，替代忙等互斥。
4. **Mind 读写口明确**：L2 直读、写经无模型串行服务；并澄清 Mind 是知识真源而非运行时状态真源（运行时状态归 SQLite，ADR-0007）。
5. **手机面过渡通道明确为钉钉 Stream 双向机器人**（原仅写「钉钉」），并将内置日程看板提前进入 MVP（ADR-0002 修订、ADR-0008）。
6. 新增引用：短期 MVP 目标以 `docs/specs/MVP-AI-Secretary-Requirements.md` 为真源，本文件只管最终形态。
