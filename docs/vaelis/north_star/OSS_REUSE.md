# 开源复用门禁（Grill O3）

## 规矩

1. **先搜再写**：新领域或大功能动手前，必须完成简短复用调研。  
2. **范围**：全 GitHub（及等价托管），**不限于** Hermes / 当前底座生态。  
3. **品牌**：对外是 Vaelis；复用代码须遵守许可证与 NOTICE/归属要求。  
4. **无调研 → 不进实现切片**（审核带宽切片的入口检查）。

## 许可证

**默认白名单（可直接采用，仍须在调研里写明）：**

- MIT  
- Apache-2.0  
- BSD-2-Clause / BSD-3-Clause  
- ISC  
- 其他明确宽松、非传染的许可（调研里论证）

**须你单独批准：**

- GPL / AGPL / LGPL 等强传染或弱传染许可  
- 无许可证 / 专有 / 源码可见但限制商用  
- 许可证与依赖树冲突不清的项目
