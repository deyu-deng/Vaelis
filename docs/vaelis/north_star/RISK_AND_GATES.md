# 风险等级与阶段门禁词汇表（已冻结）

> 真源：[GRILL_FREEZE.md](./GRILL_FREEZE.md)。本文件展开可执行细则。

## RiskLevel

| 级别 | 含义 | 过夜 | 人审 |
|---|---|---|---|
| `L0_observe` | 只读扫描、摘要、预览推送 | 可自动 | 否（可进早报） |
| `L1a_organize` | 整理/归档/缓存与日志轮转；在**已批准工作区**内格式化或小范围重构（不删库、不推远程） | 可自动 | 结果进早报 |
| `L1b_destructive_local` | 删除文件/目录、清空回收站、格式化；改系统/全局配置/开机项；装卸软件；改密钥与 `.env`；`git push` / 发布预备 | **挂起** | 是 |
| `L2_external_msg` | 外发消息、邮件动作、日历写入等 | **挂起** | 是 |
| `L3_money_or_irreversible` | 下单、转账、公开发布、不可逆破坏 | **挂起** | 强制 |
| `L4_self_modify` | 改 Vaelis 自身代码/依赖/服务配置 | **挂起** | 强制 + 报告（U1：仅分支草稿，合并/重启须人批） |

**工作区**：任务绑定的项目目录；出界一律升为 L1b 或更高。

Master 只接收：任务 id、目标一句话、风险级、阶段、摘要、待批决策——**不接收**完整工具日志。

## StageGate

| stage | 含义 | 默认门禁 |
|---|---|---|
| `intake` | 想法入库 / 澄清 | 可选 |
| `sketch` | 草图 / 大纲 / 方案 | **暂停等人** |
| `rough` | 粗模 / 初稿 / MVP | **暂停等人** |
| `refine` | 精模 / 修订 | **暂停等人** |
| `render` | 渲染 / 发布物 / 交付包 | **暂停等人** |
| `done` | 关闭 | — |

第一刀示范映射：

- **代码**：sketch(设计)→rough(骨架)→refine(实现)→render(PR/交付)
- **文档**：sketch(提纲)→rough(初稿)→refine(润色)→render(定稿)

其它类型（建模、绘画、动画、视频、会话产物等）用同一引擎注册，领域包可重（D3），Master 仍窄（W1）。

非门禁步骤（工具循环、重试、格式转换）**不打断**人。

## Night mode

- 窗口：**可配置**；默认建议 00:00–07:00（Asia/Shanghai）。
- 夜窗口内默认可跑：`L0`、`L1a`。
- `L1b` / `L2+` → `blocked_awaiting_human`，进早报 / 钉钉。
- HID 占屏任务优先放在夜窗口或明确 AFK；白天避免抢键鼠。
- **供电（K3）**：队列持久化；上电默认可续跑；若检测频繁断电，降级为只汇报、不自动续 HID 占屏。早报口径：「自上次在线以来」。

## Approval surface

人可批准：`approve_stage` | `reject_stage` | `approve_task` | `reject_task` | `defer` | `escalate`。

过渡通道：**钉钉**（摘要 + 图片/文件缩略）。  
终极通道：独立 **Vaelis App**（看板 / 批准 / 指令 / 预览；不接管鼠标）。  
桌面与手机共用同一任务状态机。
